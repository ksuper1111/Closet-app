# Closet App

This is a database-driven application built as the final project for Database Systems. The project utilizes a custom SQLite database generated from raw CSV data to track and analyze closet inventory.

## System Architecture

1. **Data Source:** Raw data collected and formatted in CSV format.
2. **Database Engine:** SQLite database generated from the normalized CSV data.
3. **Frontend:** User interface built to interface with the SQLite database and display data statistics.

## Project Deliverables

### Database Design & Implementation
* **ER Diagram & Schema:** Complete relational model showing entities, attributes, and relationships.
* **SQL Queries:** Implementation and documentation of non-trivial queries demonstrating complex data retrieval (joins, aggregations, and subqueries).

### Documentation & Presentation
* **Project Write-up:** Detailed report covering the database design, normalization, and system functionality.
* **Video Demonstration:** A walk-through video explaining the project scope, database design, and frontend interface.
